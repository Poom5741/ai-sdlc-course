# Capstone 2 Rubric: Multi-Agent System

## Total Points: 100

### Agent Design (20 points)
- [ ] 3+ specialized agents (8 pts)
- [ ] Clear role separation (6 pts)
- [ ] Well-defined capabilities (6 pts)

### Orchestration (25 points)
- [ ] Central orchestrator working (10 pts)
- [ ] Task delegation logic (8 pts)
- [ ] Error handling and recovery (7 pts)

### Tools Integration (15 points)
- [ ] Agent-specific tools (8 pts)
- [ ] Tool registry (4 pts)
- [ ] Output validation (3 pts)

### Quality Assurance (15 points)
- [ ] Output validation (5 pts)
- [ ] Confidence scoring (5 pts)
- [ ] Human-in-the-loop option (5 pts)

### Testing (15 points)
- [ ] Unit tests for agents (5 pts)
- [ ] Integration tests (5 pts)
- [ ] E2E task tests (5 pts)

### Documentation (10 points)
- [ ] Architecture diagram (4 pts)
- [ ] Capabilities matrix (3 pts)
- [ ] Setup instructions (3 pts)

## Grading Scale
- **Pass (Purple Belt)**: 70+ points
- **Merit**: 85+ points
- **Distinction**: 95+ points
