# Capstone 3: Production AI Application

**Belt Progression**: Purple → Brown | **Time**: 4-5 days

## 🎯 Overview

Ship a real, production-ready AI-powered application with monitoring, cost management, and security. This capstone demonstrates you can build AI systems that work in the real world.

## 📋 Requirements

### Must Have
1. **AI Integration**
   - Working AI feature (text generation, classification, RAG, etc.)
   - Proper prompt engineering
   - Error handling for AI failures

2. **Production Readiness**
   - Environment configuration
   - Graceful degradation when AI is unavailable
   - Request rate limiting
   - Input validation and sanitization

3. **Monitoring & Observability**
   - Request/response logging
   - Error tracking
   - AI usage metrics (tokens, latency, cost)
   - Health check endpoint

4. **Cost Management**
   - Token usage tracking
   - Cost estimation per request
   - Budget alerts or limits
   - Caching for repeated queries

5. **Security**
   - API key management (env vars, not hardcoded)
   - Input sanitization
   - Rate limiting
   - No PII in logs

6. **Deployment**
   - Deployed to a public URL
   - CI/CD pipeline
   - Environment variables configured

7. **Documentation**
   - Architecture decision records
   - Runbook for common issues
   - Cost analysis document

### Project Ideas
- AI-powered customer support chatbot
- Code review assistant
- Document summarizer with RAG
- Image analysis tool
- Automated testing generator
