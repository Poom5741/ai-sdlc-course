# Capstone 1 Rubric: AI-Assisted API Service

## Total Points: 100

### PRD & Planning (15 points)
- [ ] Clear problem statement (3 pts)
- [ ] User stories with acceptance criteria (5 pts)
- [ ] API endpoint specifications (4 pts)
- [ ] Non-functional requirements (3 pts)

### Architecture (15 points)
- [ ] System diagram present (5 pts)
- [ ] Database schema defined (5 pts)
- [ ] Security considerations addressed (5 pts)

### Implementation (30 points)
- [ ] RESTful API with 5+ endpoints (10 pts)
- [ ] Input validation on all endpoints (5 pts)
- [ ] Proper error handling (5 pts)
- [ ] Authentication implemented (5 pts)
- [ ] Code follows best practices (5 pts)

### Testing (20 points)
- [ ] Unit tests present (8 pts)
- [ ] Integration tests present (7 pts)
- [ ] Code coverage ≥ 80% (5 pts)

### CI/CD (10 points)
- [ ] GitHub Actions pipeline configured (5 pts)
- [ ] Automated testing on PR (3 pts)
- [ ] Deployment working (2 pts)

### Documentation (10 points)
- [ ] README with setup instructions (3 pts)
- [ ] API documentation (4 pts)
- [ ] Environment variables documented (3 pts)

## Grading Scale
- **Pass (Blue Belt)**: 70+ points
- **Merit**: 85+ points
- **Distinction**: 95+ points
