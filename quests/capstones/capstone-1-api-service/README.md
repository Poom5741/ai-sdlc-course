# Capstone 1: AI-Assisted API Service

**Belt Progression**: White → Blue | **Time**: 2-3 days

## 🎯 Overview

Build a complete REST API with AI assistance from requirements to deployment. This capstone tests your ability to use AI tools across the full software development lifecycle.

## 📋 Requirements

### Must Have
1. **PRD (Product Requirements Document)**
   - Clear problem statement
   - User stories with acceptance criteria
   - API endpoint specifications

2. **Architecture Design**
   - System diagram
   - Database schema
   - Authentication strategy

3. **Implementation**
   - RESTful API with at least 5 endpoints
   - Input validation
   - Error handling
   - Authentication (JWT or similar)

4. **Tests**
   - Unit tests for business logic
   - Integration tests for API endpoints
   - At least 80% code coverage

5. **CI/CD**
   - GitHub Actions pipeline
   - Automated testing on PR
   - Deployment to a hosting platform

6. **Documentation**
   - README with setup instructions
   - API documentation (OpenAPI/Swagger)
   - Environment variable documentation

### Nice to Have
- Rate limiting
- Request logging
- Health check endpoint
- Database migrations

## 🏗️ Starter Code

The `starter/` directory contains a basic project scaffold. You may use it or start from scratch.

## 🧪 Submission

1. Push your code to a GitHub repository
2. Deploy the API to a public URL
3. Submit both URLs through the submission portal

## ✅ Evaluation

See `rubric.md` for detailed grading criteria.

## 💡 Tips

- Use AI tools for each phase, but verify the output
- Write tests as you go, not after
- Document as you build, not at the end
- Start with the simplest version that works, then iterate
