# Quest 17.4: Type Migration Assistant

**Block**: 17 - AI Refactoring | **Difficulty**: 🔴 Hard | **Time**: 35 minutes

## 🎯 Learning Objectives

- Migrate JavaScript to TypeScript with proper types.
- **Type safety incrementally** — add types without breaking the build.

## 💡 Hints

- Don't type everything as `any` — infer types from usage (string operations → string, math → number).
- Convert `var` to `const`/`let`.
- Add return type annotations.
