# Quest 18.1: API Migration Tool

**Block**: 18 - AI Migration | **Difficulty**: 🟡 Medium | **Time**: 30 minutes

## 🎯 Learning Objectives

- Migrate REST endpoints to GraphQL resolvers.
- **Migrate incrementally** — wrap existing endpoints, migrate one at a time.

## 💡 Hints

- GET routes → Query resolvers.
- POST routes → Mutation resolvers (NOT Queries).
- Generate both schema string and resolver functions.
