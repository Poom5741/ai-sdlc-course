# Quest 18.4: Monolith Splitter

**Block**: 18 - AI Migration | **Difficulty**: 🔴 Hard | **Time**: 40 minutes

## 🎯 Learning Objectives

- Identify microservice boundaries in a monolith.
- **Split by domain, not by layer** — services should own a business capability.

## 💡 Hints

- Modules sharing dependencies should be grouped together, not split.
- Each service needs a clear domain reason.
- Not every module becomes its own service.
