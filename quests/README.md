# AI SDLC Workshop - Code Quests

14 coding challenges across 5 blocks, designed for hands-on learning with AI tools.

## Structure

```
quests/
├── block-1-ai-tools/           # Block 1: AI Tools Setup
│   ├── quest-01-first-completion/
│   ├── quest-02-multi-file/
│   └── quest-03-compare-tools/
├── block-2-prompt-engineering/ # Block 2: Prompt Engineering
│   ├── quest-04-fix-prompt/
│   ├── quest-05-multi-step/
│   └── quest-06-domain-specific/
├── block-3-security/           # Block 3: Security
│   ├── quest-07-spot-vulnerability/
│   ├── quest-08-fix-harden/
│   └── quest-09-security-architecture/
├── block-4-agentic-workflows/  # Block 4: Agentic Workflows
│   ├── quest-10-setup-loop/
│   ├── quest-11-generate-review-fix/
│   └── quest-12-multi-agent/
└── block-5-architecture/       # Block 5: Architecture
    ├── quest-13-rag-design/
    └── quest-14-full-system/
```

## Quest Types

| Difficulty | Count | Description |
|------------|-------|-------------|
| 🟢 Easy | 5 | Beginner-friendly, guided |
| 🟡 Medium | 5 | Requires understanding |
| 🔴 Hard | 4 | Expert level |

## Each Quest Contains

- `index.js` - Partial solution with TODO markers
- `test.js` - Automated tests
- `package.json` - Pre-configured dependencies
- `README.md` - Instructions and learning objectives

## Getting Started

```bash
# Navigate to any quest
cd quests/block-1-ai-tools/quest-01-first-completion/

# Install dependencies (if needed)
npm install

# Run tests
npm test

# Start coding!
```

## Using with StackBlitz

Each quest is designed to work with StackBlitz:

1. Push the `quests/` directory to GitHub
2. Open any quest in StackBlitz
3. Start coding immediately - no local setup needed!

### Block 3: Security (90 min)

- Quest 4.1: Set Up a Loop (15 min)

### Block 5: Architecture (75 min)
- Quest 5.1: RAG Design (20 min)
