# Quest 15.5: Review Quality Scorer

**Block**: 15 - AI Code Review | **Difficulty**: 🔴 Hard | **Time**: 30 minutes

## 🎯 Learning Objectives

- Score how useful a code review is.
- **Review the review** — learn to separate high-signal from low-signal feedback.

## 💡 Hints

- Comments like "this is bad" or "lol what" should score LOW — they're vague and unactionable.
- Score based on: actionable verbs, specific references, conciseness, docs links, politeness.
- Cap score at 100.
