# Quest 16.4: Changelog Generator

**Block**: 16 - AI Documentation | **Difficulty**: 🟡 Medium | **Time**: 25 minutes

## 🎯 Learning Objectives

- Generate changelogs from conventional commit messages.
- **Automate release notes** — changelogs generated from commits, not hand-written.

## 💡 Hints

- `feat!:` (breaking changes) should be in their own ⚠ Breaking Changes section.
- Each entry should include the commit hash and date.
