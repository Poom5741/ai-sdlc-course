# Quest 16.3: API Doc Generator

**Block**: 16 - AI Documentation | **Difficulty**: 🟡 Medium | **Time**: 25 minutes

## 🎯 Learning Objectives

- Generate OpenAPI specs from route handlers.
- **Document the interface** — API docs should be generated from code.

## 💡 Hints

- HTTP methods must stay uppercase (GET, POST, DELETE) — only use lowercase for object keys.
- Parameters should be extracted from route.params and added as query parameters.
