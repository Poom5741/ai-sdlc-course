# Quest 16.5: Onboarding Doc Writer

**Block**: 16 - AI Documentation | **Difficulty**: 🔴 Hard | **Time**: 30 minutes

## 🎯 Learning Objectives

- Generate comprehensive onboarding documentation.
- **Document for the newcomer** — write as if the reader has never seen the codebase.

## 💡 Hints

- Stack items should include version/tool details (e.g., "Node.js v18 — runtime"), not just names.
- Key files should be in table format.
- Include 3 starter tasks for new team members.
