# Quest 16.1: Docstring Generator

**Block**: 16 - AI Documentation | **Difficulty**: 🟢 Easy | **Time**: 15 minutes

## 🎯 Learning Objectives

- Generate JSDoc docstrings from function signatures.
- **Document the contract** — every function should describe params, return type, and behavior.

## 💡 Hints

- Empty parameter lists should produce NO @param tags.
- Docstrings must appear ABOVE the function definition.
- Handle both `function foo()` and `const foo = () =>` patterns.
