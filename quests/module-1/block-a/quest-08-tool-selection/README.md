# Quest 1.8: AI Tool Selection Matrix

**Block**: 1 - AI Tools Setup | **Difficulty**: 🟡 Medium | **Time**: 25 minutes

## 🎯 Learning Objectives

- Evaluate and select the right AI tool for a given task.
- **Tool selection matters** — different AI tools have different strengths.

## 📋 Instructions (run on your machine)

```bash
npx degit Poom5741/ai-sdlc-course/quests/module-1/block-a/quest-08-tool-selection my-quest
cd my-quest
```

1. **Create `tool-matrix.md`** in this folder.
2. **Write your matrix** comparing at least 3 AI tools with:
   - Comparison criteria (speed, accuracy, cost, context window, etc.)
   - A scoring system (1-5 or similar)
   - Recommendations for different use cases
   - Limitations of each tool
3. **Verify:**
   ```bash
   node test.js
   ```

## ✅ Verification

`node test.js` is a **design-doc validator** — it checks that `tool-matrix.md` exists and contains the required sections with ≥ 400 characters.

## 💡 Hints

- Include tools like Copilot, Claude Code, Cursor, CodeWhisperer, Codeium.
- Score each tool on criteria that matter for your use case.
- Be honest about limitations — every tool has weaknesses.
