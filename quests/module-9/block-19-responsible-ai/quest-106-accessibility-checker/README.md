# Quest 19.4: Accessibility Checker

**Block**: 19 - Responsible AI | **Difficulty**: 🔴 Hard | **Time**: 30 minutes

## 🎯 Learning Objectives

- Audit code for accessibility violations.
- **Accessibility is not optional** — build it in from the start.

## 💡 Hints

- Decorative images with `role="presentation"` don't need alt text.
- Check for missing alt, labels, button text, and heading level skips.
- Each violation should have rule, severity, line number, and message.
