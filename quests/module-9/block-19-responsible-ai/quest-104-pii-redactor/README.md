# Quest 19.2: PII Redactor

**Block**: 19 - Responsible AI | **Difficulty**: 🟡 Medium | **Time**: 25 minutes

## 🎯 Learning Objectives

- Detect and redact personal information from text.
- **Privacy by default** — redact PII before logging or sharing.

## 💡 Hints

- `test@example.com` is example data, not real PII — skip it.
- Redact emails, phones, SSNs, and names after "My name is" / "I'm".
- Return both the redacted text and counts of what was found.
