# Quest 20.4: Multimodal RAG System

**Block**: 20 - Multimodal AI | **Difficulty**: 🔴 Hard | **Time**: 40 minutes

## 🎯 Learning Objectives

- Build a RAG system that handles text, images, and tables.
- **Unified retrieval** — different data types, one interface.

## 💡 Hints

- Images need metadata-based scoring (alt text, tags), not content-based.
- Tables need column-name matching.
- Visual queries (show me, look at) should boost image scores.
