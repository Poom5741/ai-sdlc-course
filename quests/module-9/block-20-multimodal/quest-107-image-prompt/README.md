# Quest 20.1: Image Prompt Engineer

**Block**: 20 - Multimodal AI | **Difficulty**: 🟢 Easy | **Time**: 20 minutes

## 🎯 Learning Objectives

- Write effective prompts for image generation models.
- **Precision in prompts** — specific prompts produce specific images.

## 💡 Hints

- Structure: subject, style, composition, lighting, mood.
- Include before/after examples of bad vs good prompts.
- Cover multiple model tips (DALL-E, Midjourney, Stable Diffusion).
