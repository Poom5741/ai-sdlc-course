# Quest 20.2: Multimodal Input Processor

**Block**: 20 - Multimodal AI | **Difficulty**: 🟡 Medium | **Time**: 30 minutes

## 🎯 Learning Objectives

- Process combined text + image inputs.

## 💡 Hints

- Generate [IMAGE] placeholders in combined prompt.
