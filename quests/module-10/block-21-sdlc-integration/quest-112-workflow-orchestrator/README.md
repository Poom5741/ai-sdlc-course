# Quest 21.2: Multi-Tool Workflow Orchestrator

**Block**: 21 - Full SDLC Integration | **Difficulty**: 🔴 Hard | **Time**: 45 minutes

## 🎯 Learning Objectives

- Coordinate multiple AI tools in a workflow.
- **Orchestrate, don't overbuild** — use existing tools together.

## 💡 Hints

- Workflow must STOP on first error (fail-fast).
- Each tool receives the previous tool's output.
- Record all steps for auditability.
