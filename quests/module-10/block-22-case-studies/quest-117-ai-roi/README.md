# Quest 22.3: AI ROI Calculator

**Block**: 22 - Industry Case Studies | **Difficulty**: 🟡 Medium | **Time**: 25 minutes

## 🎯 Learning Objectives

- Calculate ROI of AI development tools.
- **Measure value** — justify investment with numbers.

## 💡 Hints

- If costs exceed savings, ROI must be NEGATIVE.
- Break-even is Infinity when the tool never pays for itself.
- ROI is a percentage: ((savings - cost) / cost) * 100.
