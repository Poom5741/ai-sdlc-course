# ADR 0001: Workshop Format - One Day Intensive

## Status
Accepted

## Context
We need to create a modern AI SDLC course that:
- Covers almost every area of AI-assisted development
- Targets both non-tech beginners and experienced devs struggling with vibe coding
- Provides hands-on practice, not just theory
- Fits into a manageable time commitment

## Decision
**One-day, 8-hour workshop** with interleaved 90-minute blocks:
- 30 minutes: Concept introduction (theory)
- 60 minutes: CTF challenge (hands-on practice)

### Structure
```
09:00 - 10:30  Block 1: AI Tools Setup + First Challenge
10:45 - 12:15  Block 2: Prompt Engineering + Challenge
12:15 - 13:15  Lunch Break
13:15 - 14:45  Block 3: Security + Challenge
15:00 - 16:30  Block 4: Agentic Workflows + Challenge
16:45 - 18:00  Block 5: Architecture + Final Challenge + Wrap-up
```

## Consequences

### Positive
- High energy: Short theory segments keep attention
- Immediate application: Learners practice right away
- Manageable commitment: One day, not weeks
- Social: Group challenges build community

### Negative
- Time pressure: Must be selective about topics
- Setup required: Learners need environment ready before workshop
- Follow-up needed: One day isn't enough for mastery

### Mitigations
- Pre-workshop setup guide
- Interactive docs for continued learning
- CTF challenges available after workshop
