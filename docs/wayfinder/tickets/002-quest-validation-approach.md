# Ticket: Quest Validation Approach

## Question

How should we validate that learners completed each Code Quest correctly?

### Context
- 14 code quests across 5 blocks
- Mix of difficulty levels (Easy/Medium/Hard)
- Need immediate feedback for learners
- Workshop setting (8 hours total)

### Decision needed
1. Automated validation vs manual review?
2. What tool/approach for each quest type?
3. How to handle partial completion?
4. Certificate/badge system?

### Options to consider
- Automated tests (run in browser/CLI)
- Screenshot submission + manual review
- AI-assisted grading
- Peer review
- Self-assessment checklists

## Acceptance criteria
- [ ] Validation method defined for each quest type
- [ ] Feedback mechanism documented
- [ ] Partial completion handling clear
