Key Difference:
Merge: Creates a merge commit (merge-abc) with TWO parents. History is preserved exactly as it happened.
Rebase: Replays feature commits ON TOP of main. History is rewritten to look linear. New commit hashes are generated.

When to Use Each

  • Merge — Safe for shared branches, preserves full history, default on GitHub PRs
  • Rebase — Clean linear history, good for local branches before sharing, never rebase pushed commits
