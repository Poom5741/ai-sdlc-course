# AI-Assisted API Service

<Badge text="White → Blue Belt" variant="caution" /> <Badge text="Multi-day project" variant="note" />

## ภาพรวม

สร้าง REST API แบบสมบูรณ์ด้วยความช่วยเหลือของ AI ตั้งแต่ requirements จนถึง deployment This capstone tests your ability to use AI tools effectively throughout the entire software development lifecycle.

## Prerequisites

- **Current Belt:** White
- **Quests Completed:** At least 20 quests
- **Modules Covered:** Module 1-3 basics

## ข้อกำหนด

### Phase 1: Planning (Day 1)
- [ ] Write a Product Requirements Document (PRD) for your API
- [ ] Create Architecture Decision Records (ADRs) for key choices
- [ ] Define API endpoints using OpenAPI/Swagger spec
- [ ] Set up project repository with proper structure

### Phase 2: Development (Day 2-3)
- [ ] Implement core API endpoints with proper error handling
- [ ] Add input validation for all endpoints
- [ ] Implement authentication (JWT recommended)
- [ ] Write unit tests with >80% coverage
- [ ] Use AI tools for code generation AND review

### Phase 3: Quality (Day 4)
- [ ] Security review: no SQL injection, no hardcoded secrets
- [ ] Performance: response times under 200ms for simple queries
- [ ] Documentation: README with setup instructions
- [ ] Code review: fix all AI-generated code issues

### Phase 4: Deployment (Day 5)
- [ ] Set up CI/CD pipeline (GitHub Actions)
- [ ] Deploy to a cloud platform
- [ ] Configure monitoring/logging
- [ ] Write deployment documentation

## Rubric

| Criteria | Weight | Description |
|----------|--------|-------------|
| **Architecture** | 25% | Clean separation of concerns, proper patterns, scalable design |
| **Code Quality** | 25% | No security vulnerabilities, proper error handling, clean code |
| **Testing** | 20% | Unit tests, integration tests, edge cases covered |
| **Documentation** | 15% | README, API docs, inline comments where needed |
| **AI Usage** | 15% | Effective use of AI tools, human review of AI output |

## Evaluation

Your submission will be evaluated on:

1. **Functional Completeness** - Does it do what the PRD says?
2. **Code Quality** - Is it maintainable and secure?
3. **Testing** - Are there adequate tests?
4. **Documentation** - Can someone else understand and deploy it?
5. **AI Integration** - Did you use AI tools effectively and responsibly?

## Submission

1. Push your code to a GitHub repository
2. Deploy your application (if applicable)
3. Submit both URLs through the submission portal in your dashboard
4. Include a brief write-up of your AI usage patterns

## Tips

- Start with the PRD before writing any code
- Use AI for boilerplate but review everything carefully
- Write tests as you go, not at the end
- Document as you build, not after
- Ask for feedback in the Discord community
