## Challenge 1.1: Install GitHub Copilot

<Steps>

1. Open VS Code

2. Go to Extensions (Ctrl+Shift+X)

3. Search for "GitHub Copilot Chat"

4. Install the extension

5. Sign in with your GitHub account

6. Verify Copilot is working (see green checkmark in status bar)

</Steps>

## Challenge 1.2: First Code Completion

<Steps>

1. Create a new file called `factorial.js`

2. Type this comment:
```javascript
// Calculate factorial of n using recursion
```

3. Press Enter and let Copilot suggest the implementation

4. Accept the suggestion (Tab key)

5. Test your function:
```javascript
console.log(factorial(5)); // Should output 120
```

</Steps>

## Challenge 1.3: Compare Tools

<Steps>

1. Open Claude Code in your terminal:
```bash
claude
```

2. Ask Claude to write the same factorial function:
```
Write a JavaScript function to calculate factorial using recursion
```

3. Compare the output with Copilot's version

4. Document the differences in a markdown file:
```markdown
# Copilot vs Claude Code Comparison

## Copilot Output
[Copy Copilot's code here]

## Claude Code Output
[Copy Claude's code here]

## Differences
- Difference 1
- Difference 2

## Which is better? Why?
[Your analysis]
```

</Steps>
