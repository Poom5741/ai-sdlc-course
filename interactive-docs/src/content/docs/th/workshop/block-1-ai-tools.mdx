## 📖 Concept: ภูมิทัศน์เครื่องมือ AI (30 นาที)

### AI-Assisted Development คืออะไร?

AI-Assisted Development คือการใช้เครื่องมือ AI เพื่อช่วยเขียนโค้ดได้เร็วและดีขึ้น

### การเปลี่ยนแปลง: Manual → AI-Assisted

```
ก่อน: คิด → เขียนโค้ด → Debug → Test
หลัง: คิด → บอก AI → Review → Refine → Deploy
```

### Key Concepts

#### Tokens

- หน่วยเล็กที่สุดของข้อความที่ AI อ่าน
- แต่ละ token อาจเป็นคำหรือส่วนหนึ่งของคำ
- สำคัญเพราะมีผลต่อต้นทุนและ context window

#### Context Window

- ปริมาณข้อมูลที่ AI จดจำได้พร้อมกัน
- มากขึ้น = จดจำมากขึ้น = ดีขึ้น

#### Hallucination

- เมื่อ AI สร้างสิ่งที่ไม่มีอยู่จริง
- ต้องตรวจสอบ output เสมอ

## 🛠️ ภาพรวมเครื่องมือ

### GitHub Copilot

- **อะไร**: AI pair programmer ใน VS Code
- **ทำอย่างไร**: แนะนำโค้ดขณะพิมพ์
- **เหมาะสำหรับ**: Inline code completion

### Claude Code

- **อะไร**: AI assistant แบบ terminal
- **ทำอย่างไร**: สนทนาใน terminal, execute commands
- **เหมาะสำหรับ**: Complex tasks, debugging

### CodeRabbit

- **อะไร**: AI code review
- **ทำอย่างไร**: Review PRs อัตโนมัติ
- **เหมาะสำหรับ**: Quality assurance

## 🎮 Code Quests

### 🟢 Quest 1.1: First AI Completion

**เป้าหมาย**: ใช้ GitHub Copilot เขียน function

<Steps>

1. **ติดตั้ง GitHub Copilot**
   - เปิด VS Code
   - ไปที่ Extensions (Ctrl+Shift+X)
   - ค้นหา "GitHub Copilot Chat"
   - ติดตั้งและ sign in

2. **สร้างไฟล์ใหม่**

   ```javascript
   // factorial.js
   ```

3. **เขียน comment**

   ```javascript
   // Calculate factorial of n using recursion
   ```

4. **ยอมรับคำแนะนำของ Copilot** (กด Tab)

5. **ทดสอบ function**

   ```javascript
   console.log(factorial(5)); // ควร output 120
   console.log(factorial(10)); // อะไรออกมา?
   ```

</Steps>

**ส่งมอบ**: factorial function ที่ทำงานได้ + screenshot
