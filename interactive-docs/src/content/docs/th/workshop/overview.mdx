## ภาพรวมหลักสูตร

เรียนรู้การพัฒนาซอฟต์แวร์สมัยใหม่ด้วย AI ตั้งแต่การตั้งค่าเครื่องมือไปจนถึงการออกแบบระบบ

### 🎯 ผลลัพธ์การเรียนรู้

เมื่อจบหลักสูตรนี้ คุณจะสามารถ:

1. **ตั้งค่า**: ติดตั้งและกำหนดค่าเครื่องมือ AI coding
2. **Prompt**: เขียน prompt ที่มีประสิทธิภาพสำหรับ code generation
3. **Review**: ระบุปัญหาด้านความปลอดภัยในโค้ดที่สร้างด้วย AI
4. **Loop**: ตั้งค่า automated development loops
5. **Agent**: ออกแบบ agentic workflows
6. **Architect**: ตัดสินใจเกี่ยวกับ AI integration
7. **Pipeline**: ใช้ AI Development Pipeline ครบวงจร (Planning → Tracking → Execution)
