## 📖 Concept: LLM Observability (25 นาที)

### LLM Observability คืออะไร?

LLM Observability คือการ monitor, trace, และ debug สิ่งที่เกิดขึ้นภายใน LLM applications:

### ทำถึง Observability สำคัญสำหรับ LLMs

**ความท้าทายเฉพาะ LLM:**

- **Non-deterministic** — ผลลัพธ์ต่างกันแม้ input เดียวกัน
- **Hallucination** — สร้างข้อมูลเท็จ
- **Token costs** — แพงและคาดเดายาก
- **Latency** — ช้ากว่า APIs ทั่วไป
- **Quality drift** — คุณภาพเปลี่ยนเมื่อ model อัปเดต

### Key Metrics สำหรับ LLM Apps

```
Performance:
├── Latency (time to first token, total)
├── Throughput (requests per second)
└── Error rate (failed requests)

Cost:
├── Tokens per request
├── Cost per request
└── Cost per user/project

Quality:
├── User satisfaction scores
├── Hallucination rate
└── Task completion rate
```

## 🔍 Hallucination Detection

### Hallucination คืออะไร?

LLM สร้างข้อมูลเท็จหรือขัดแย้งกับข้อมูลที่ให้ไว้

**สัญญาณของ Hallucination:**

- ขัดแย้งกับ context ที่ให้
- สร้างข้อเท็จจริงที่ไม่มีใน source material
- มั่นใจเกินไปเกี่ยวกับเรื่องที่ไม่แน่ใจ
- อ้างอิง sources ที่ไม่มีอยู่

### Detection Strategies

```javascript
function detectHallucination(output, sources) {
  const issues = [];

  // 1. Source verification
  const claims = extractClaims(output);
  for (const claim of claims) {
    if (!isSupportedBySources(claim, sources)) {
      issues.push({
        type: 'unsupported_claim',
        claim,
        confidence: 0.8
      });
    }
  }

  // 2. Consistency check
  if (containsContradictions(output)) {
    issues.push({
      type: 'contradiction',
      confidence: 0.7
    });
  }

  // 3. Confidence scoring
  const confidenceScore = calculateConfidence(output, sources);

  return { hasHallucination: issues.length > 0, issues, confidenceScore };
}
```

## 💰 Cost Monitoring

### ติดตาม Token Usage

```javascript
async function callWithTracking(prompt, model) {
  const start = Date.now();
  const response = await llm.complete(prompt, { model });
  const tokens = countTokens(prompt) + countTokens(response);
  const cost = calculateCost(model, tokens);
  const latency = Date.now() - start;

  await logMetric({ model, tokens, cost, latency, timestamp: Date.now() });
  return response;
}
```

### เคล็ดลดต้นทุน

1. **Cache common queries** — หลีกเลี่ยง LLM calls ที่ซ้ำ
2. **ใช้ models เล็กสำหรับ tasks ง่าย** — routing
3. **Trim context** — ลด input tokens
4. **กำหนด token limits** — ป้องกัน output ที่ยาวเกินไป
