## Instructions

<Steps>

1. Download the quest starter code:
   ```bash
   npx bluebeltdojo download quest-111-e2e-pipeline
   cd quest-111-e2e-pipeline
   ```

2. Open `problem.js` in your editor with AI assistance.

3. Implement the solution following the instructions in `problem.js`.

4. Verify your solution:
   ```bash
   node test.js
   ```
