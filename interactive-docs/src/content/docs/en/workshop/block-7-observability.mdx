## 📖 Concept: LLM Observability (25 min)

### What is LLM Observability?

LLM Observability is monitoring, tracing, and debugging what happens inside LLM applications:

<CardGrid>
<Card title="Tracing" icon="search">
Track requests through the system
</Card>
<Card title="Metrics" icon="chart">
Measure latency, cost, quality
</Card>
<Card title="Logs" icon="document">
Log inputs, outputs, errors
</Card>
<Card title="Alerts" icon="warning">
Alert when issues occur
</Card>
</CardGrid>

### Why Observability Matters for LLMs

**LLM-specific challenges:**

- **Non-deterministic** — different results even with same input
- **Hallucination** — generates false information
- **Token costs** — expensive and unpredictable
- **Latency** — slower than typical APIs
- **Quality drift** — quality changes with model updates

### Key Metrics for LLM Apps

```
Performance:
├── Latency (time to first token, total)
├── Throughput (requests per second)
└── Error rate (failed requests)

Cost:
├── Tokens per request
├── Cost per request
└── Cost per user/project

Quality:
├── User satisfaction scores
├── Hallucination rate
└── Task completion rate
```

## 🔍 Hallucination Detection

### What is Hallucination?

LLM generates false or inconsistent information compared to provided data

**Signs of Hallucination:**

- Contradicts the provided context
- Fabricates facts not in source material
- Overconfident about uncertain topics
- References non-existent sources

### Detection Strategies

```javascript
function detectHallucination(output, sources) {
  const issues = [];
  
  // 1. Source verification
  const claims = extractClaims(output);
  for (const claim of claims) {
    if (!isSupportedBySources(claim, sources)) {
      issues.push({
        type: 'unsupported_claim',
        claim,
        confidence: 0.8
      });
    }
  }
  
  // 2. Consistency check
  if (containsContradictions(output)) {
    issues.push({
      type: 'contradiction',
      confidence: 0.7
    });
  }
  
  // 3. Confidence scoring
  const confidenceScore = calculateConfidence(output, sources);
  
  return {
    hasHallucination: issues.length > 0,
    issues,
    confidenceScore
  };
}
```

## 💰 Cost Monitoring

### Track Token Usage

```javascript
async function callWithTracking(prompt, model) {
  const start = Date.now();
  
  const response = await llm.complete(prompt, { model });
  
  const tokens = countTokens(prompt) + countTokens(response);
  const cost = calculateCost(model, tokens);
  const latency = Date.now() - start;
  
  // Log for monitoring
  await logMetric({
    model,
    tokens,
    cost,
    latency,
    timestamp: Date.now()
  });
  
  return response;
}
```

### Cost Optimization Tips

1. **Cache common queries** — avoid repeated LLM calls
2. **Use smaller models for simple tasks** — routing
3. **Trim context** — reduce input tokens
4. **Set token limits** — prevent runaway outputs
