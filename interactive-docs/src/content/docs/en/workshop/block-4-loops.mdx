## 📖 Concept: Agentic Workflows (30 min)

### What are Agentic Workflows?

Agentic Workflows are systems where AI agents work together autonomously to achieve goals

### The PIV Framework

**Plan-Implement-Validate** is the core pattern:

```
┌─────────────┐
│    PLAN     │  Analyze work, break into steps
└──────┬──────┘
       │
       ▼
┌─────────────┐
│  IMPLEMENT  │  Generate code per plan
└──────┬──────┘
       │
       ▼
┌─────────────┐
│  VALIDATE   │  Test, verify quality
└──────┬──────┘
       │
       ▼
   Pass? ──Yes──► Done
       │
       No
       │
       └──────► Back to PLAN
```

### Why Use Loops?

- **Quality**: Verify before deploy
- **Iteration**: Improve every iteration
- **Automation**: Reduce manual work
- **Consistency: Consistent results every time

---

## 🛠️ Loop Patterns

### Pattern 1: Generate-Review-Fix

```
Generate Code → AI Review → Fix Issues → Repeat until quality
```

### Pattern 2: Test-Driven Loop

```
Write Test → Generate Code → Run Test → Fix → Repeat
```

### Pattern 3: Multi-Agent Pipeline

```
Planner → Coder → Reviewer → Tester → Deploy
```

### Convergence Criteria

Loops should stop when:

- Quality gate passes (e.g. 90% test coverage)
- No critical issues
- Max iterations reached

### Loop Engineering with Pi

**Loop Engineering** is designing systems where AI iterates until goals are achieved

#### Pattern 1: Single Agent Loop

```bash
# Pi works alone, iterating until done
pi --loop "Create a REST API with auth, tests, and docs"
```

**What Pi does:**

1. Plan
2. Generate code (Implement)
3. Run tests (Validate)
4. Fix if fails
5. Repeat until tests pass

#### Pattern 2: Subagent Fan-out

```bash
# Pi Create subagents for parallel work
pi "Build frontend, backend, and docs in parallel"
```

**What Pi does:**

1. Analyzes how many independent tasks exist
2. Create each subagent
3. Work simultaneously (parallel)
4. Aggregates results
5. Verifies quality

#### Pattern 3: Pipeline Flow

```text
User Request
    │
    ▼
┌─────────┐     ┌─────────┐     ┌─────────┐
│ Planner │────▶│  Coder  │────▶│ Reviewer │
└─────────┘     └─────────┘     └────┬────┘
                                     │
                           ┌─────────┘
                           ▼
                     ┌─────────┐
                     │  Tester │
                     └─────────┘
```

**In Pi:**

- `/workflow` — Build pipeline with multiple agents
- `parallel()` — Work in parallel
- `pipeline()` — Work step by step

### Practical Examples with Pi

#### Example 1: Parallel Code Review

```text
# Have Pi review code from 3 perspectives simultaneously
Pi workflow:
  parallel([
    agent("Review for security issues"),
    agent("Review for performance"),
    agent("Review for code quality")
  ])
```

#### Example 2: Feature Implementation Loop

```text
# Pi works on feature until complete
Pi workflow:
  loopUntilDone(
    plan → implement → test → verify
  )
```

#### Example 3: Research + Implement

```text
# Pi researches before implementing
Pi workflow:
  pipeline([
    agent("Research best practices for X"),
    agent("Implement based on research"),
    agent("Write tests"),
    agent("Deploy")
  ])
```
