## Workshop Overview

Learn modern software development with AI, from tool setup to system design

### 🎯 Learning Outcomes

By the end of this workshop, you will be able to:

1. **Setup**: Install and configure AI coding tools
2. **Prompt**: Write effective prompts for code generation
3. **Review**: Identify security issues in AI-generated code
4. **Loop**: Set up automated development loops
5. **Agent**: Design agentic workflows
6. **Architect**: Make decisions about AI integration
7. **Pipeline**: Use the complete AI Development Pipeline (Planning → Tracking → Execution)

## 🚀 Getting Started with the CLI

BlueBeltDojo CLI helps you download, test, and submit quest solutions easily:

<Steps>

1. **Setup access code** (first time only):
   ```bash
   npx bluebeltdojo setup <your-access-code>
   ```

2. **List available quests**:
   ```bash
   npx bluebeltdojo list
   ```

3. **Download a quest**:
   ```bash
   npx bluebeltdojo download quest-01-first-completion
   cd quest-01-first-completion
   ```

4. **Test locally**:
   ```bash
   node test.js
   ```

5. **Submit your solution**:
   ```bash
   npx bluebeltdojo submit
   ```

</Steps>

> 💡 CLI works offline for testing — must be online only when submitting
