## 📖 Concept: The AI Toolkit Landscape (30 min)

### What is AI-Assisted Development?

AI-assisted development is using AI tools to help write code faster and better.

### The Shift: Manual → AI-Assisted

```
Before: Think → Write code → Debug → Test
After:  Think → Tell AI → Review → Refine → Deploy
```

### Key Concepts

#### Tokens

- Smallest units of text that AI reads
- Each token may be a word or part of a word
- Important because they affect cost and context window

#### Context Window

- Amount of data AI can remember at once
- More = remembers more = better

#### Hallucination

- When AI generates something that doesn't exist
- Always verify outputs

## 🛠️ Tools Overview

### GitHub Copilot

- **What**: AI pair programmer in VS Code
- **How**: Suggests code as you type
- **Best for**: Inline code completion

### Claude Code

- **What**: Terminal-based AI assistant
- **How**: Chat in terminal, execute commands
- **Best for**: Complex tasks, debugging

### CodeRabbit

- **What**: AI code review
- **How**: Reviews PRs automatically
- **Best for**: Quality assurance

## 🎮 Code Quests

### 🟢 Quest 1.1: First AI Completion

**Goal**: Use GitHub Copilot to write a function

<Steps>

1. **Install GitHub Copilot**
   - Open VS Code
   - Go to Extensions (Ctrl+Shift+X)
   - Search "GitHub Copilot Chat"
   - Install and sign in

2. **Create a new file**

   ```javascript
   // factorial.js
   ```

3. **Write a comment**

   ```javascript
   // Calculate factorial of n using recursion
   ```

4. **Accept Copilot's suggestion** (Tab key)

5. **Test your function**

   ```javascript
   console.log(factorial(5)); // Should output 120
   console.log(factorial(10)); // What does this output?
   ```

</Steps>

**Deliverable**: Working factorial function + screenshot
