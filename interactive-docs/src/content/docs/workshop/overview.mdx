## Workshop Overview

เรียนรู้การพัฒนาซอฟต์แวร์ยุคใหม่ด้วย AI ตั้งแต่การตั้งค่าเครื่องมือไปจนถึงการออกแบบระบบ

### 🎯 Learning Outcomes

เมื่อเรียนจบ workshop นี้ คุณจะสามารถ:

1. **Setup**: ติดตั้งและตั้งค่า AI coding tools
2. **Prompt**: เขียน prompts ที่มีประสิทธิภาพสำหรับ code generation
3. **Review**: ระบุปัญหาด้านความปลอดภัยใน AI-generated code
4. **Loop**: ตั้งค่า automated development loops
5. **Agent**: ออกแบบ agentic workflows
6. **Architect**: ตัดสินใจเรื่อง AI integration
7. **Pipeline**: ใช้ AI Development Pipeline ครบวงจร (Planning → Tracking → Execution)

## 📚 What You'll Learn

### Block 1: AI Tools
- GitHub Copilot setup and usage
- Claude Code for terminal-based AI
- Comparing different AI tools

### Block 2: Prompt Engineering
- Writing effective prompts
- Iterative refinement
- Domain-specific prompting

### Block 3: Security
- Common vulnerabilities in AI code
- SQL injection, hardcoded secrets
- Security hardening techniques

### Block 4: Loop Engineering
- Plan-Implement-Validate (PIV) framework
- Self-healing loops
- Multi-agent pipelines

### Block 5: Architecture
- System design with AI
- RAG architecture
- Final project

### Block 6: AI Development Pipeline
- Matt Pocock's skills for planning
- GitHub Issues as decision tickets
- Goal system for autonomous execution
- Anti-bamboozle architecture
- Impeccable, Ponytail, and Pi Agent skills
