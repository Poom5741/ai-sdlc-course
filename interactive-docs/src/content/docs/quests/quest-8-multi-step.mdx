## 📖 Concept: Tool Selection Matrix

ไม่ใช่ AI tool ทุกตัวจะเหมาะกับทุกงาน — เช่นเดียวกับช่างไม้ที่มีเครื่องมือหลายอย่าง แต่ละอย่างมีจุดแข็งต่างกัน

**Tool Selection Matrix** คือตารางเปรียบเทียบที่ช่วยให้คุณเลือก tool ที่เหมาะสมกับงาน มี criteria ชัดเจน และ scoring system ที่เป็นธรรม

---

## ⚙️ How It Works

### Criteria ที่ควรพิจารณา

| Criteria | นิยาม | ตัวอย่าง |
| --- | --- | --- |
| **Speed** | เร็วแค่ไหน | 2s vs 5s |
| **Accuracy** | ถูกต้องแค่ไหน | 80% vs 95% |
| **Cost** | ราคาเท่าไหร่ | ฟรี vs $20/เดือน |
| **Context Window** | รับ tokens ได้มากแค่ไหน | 4K vs 128K |
| **Ease of Use** | ใช้งานง่ายแค่ไหน | CLI vs GUI |
| **Integration** | เชื่อมกับเครื่องมืออื่นได้แค่ไหน | GitHub vs VS Code |

### Scoring System

```javascript
// คะแนน 1-5
const scores = {
  copilot: {
    speed: 5,      // เร็วมาก
    accuracy: 4,   // ถูกต้องดี
    cost: 3,       // $10/เดือน
    context: 4,    // 128K tokens
    easeOfUse: 5,  // ใช้งานง่ายใน IDE
    integration: 5  // GitHub integration
  },
  claudeCode: {
    speed: 3,      // ช้ากว่า
    accuracy: 5,   // ถูกต้องมาก
    cost: 3,       // $20/เดือน
    context: 5,    // 200K tokens
    easeOfUse: 4,  // CLI based
    integration: 3  // น้อยกว่า
  }
};
```

## 💡 Example: Creating a Matrix

**ขั้นตอนที่ 1: เลือก tools ที่จะเปรียบเทียบ**

```javascript
// เลือก 3 tools
const tools = ['GitHub Copilot', 'Claude Code', 'Cursor'];
```

**ขั้นตอนที่ 2: กำหนด criteria**

```javascript
const criteria = ['speed', 'accuracy', 'cost', 'contextWindow', 'easeOfUse'];
```

**ขั้นตอนที่ 3: ให้คะแนน**

```javascript
// ให้คะแนน 1-5 สำหรับแต่ละ criteria
const matrix = {
  'GitHub Copilot': { speed: 5, accuracy: 4, cost: 3, contextWindow: 4, easeOfUse: 5 },
  'Claude Code':    { speed: 3, accuracy: 5, cost: 3, contextWindow: 5, easeOfUse: 4 },
  'Cursor':         { speed: 4, accuracy: 4, cost: 4, contextWindow: 4, easeOfUse: 5 }
};
```

**ขั้นตอนที่ 4: คำนวณ total score**

```javascript
function calculateTotal(scores) {
  return Object.values(scores).reduce((sum, score) => sum + score, 0);
}

// Copilot: 5+4+3+4+5 = 21
// Claude Code: 3+5+3+5+4 = 20
```

## ⚠️ Common Mistakes

**Mistake 1: ให้คะแนน subjective**
> "Claude ดีกว่าเพราะฉันชอบ"
> → ต้องมี criteria ชัดเจนและ objective

**Mistake 2: ลืม考虑 limitations**
> ให้คะแนนแค่จุดแข็ง ไม่ดูจุดอ่อน
> → ต้อง include limitations ด้วย

**Mistake 3: ไม่ match criteria กับ use case**
> ใช้ criteria เดียวกันสำหรับทุก use case
> → ปรับ criteria ตาม use case (prototype vs production)

**Mistake 4: ไม่ update matrix**
> ใช้ matrix เดิมโดยไม่อัพเดท
> → AI tools พัฒนาเร็ว ต้อง update บ่อยๆ
