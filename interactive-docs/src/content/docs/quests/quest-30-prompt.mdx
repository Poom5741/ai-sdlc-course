## 📖 Concept: Prompt Refinement — เขียน prompt ให้ดีพอที่ AI จะเข้าใจ

Prompt-for-Code Refiner คือการ **ปรับปรุง prompt ที่คลุมเครือให้ชัดเจนขึ้น** — เพราะ prompt ที่สั้นและคลุมเครือ = code ที่ AI เขียนก็จะคลุมเครือตามไปด้วย

คิดง่ายๆ: ถ้าบอกช่างซ่อมรถว่า "รถมีปัญหา" เขาจะงง — แต่ถ้าบอกว่า "เครื่องยนต์สตาร์ทไม่ติดตอนเช้า อากาศเย็น" เขาจะแก้ได้ทันที

Prompt refinement คือการเปลี่ยนจาก:

```
❌ "write a function"
```

เป็น:

```
✅ "write a function that takes an array of numbers, 
    returns the average, and throws an error for empty arrays"
```

---

## ⚙️ How It Works

### Prompt Refinement Workflow

```
1. ได้ prompt คลุมเครือ (badPrompt)
         ↓
2. วิเคราะห์ว่าขาดอะไร (parameters? types? edge cases?)
         ↓
3. เพิ่ม specificity
         ↓
4. ตรวจสอบว่า prompt ใหม่ดีกว่าเดิม
```

### What Makes a Prompt "Bad"?

**Missing parameters** — ไม่บอกว่ารับ input อะไร

```
❌ "write a function"
✅ "write a function that takes a string and returns its reverse"
```

**Missing types** — ไม่บอก data types

```
❌ "write a sorting function"
✅ "write a function that takes an array of numbers and returns them sorted ascending"
```

**Missing edge cases** — ไม่บอกว่าต้อง handle อะไร

```
❌ "write a login function"
✅ "write a login function that validates email format, checks password length >= 8, and throws on invalid credentials"
```

## 💡 Example: The Right Way

**Step 1: ดู prompt คลุมเครือ**

```javascript
const badPrompt = "write a function";
```

**Step 2: วิเคราะห์และเพิ่ม specificity**

```javascript
function refinePrompt(badPrompt) {
  // วิเคราะห์ว่า prompt คลุมเครือตรงไหน
  const hasFunction = /function/i.test(badPrompt);
  const hasParams = /\(.*\)|parameter|input|arg/i.test(badPrompt);
  const hasType = /string|number|array|object|boolean/i.test(badPrompt);
  const hasReturn = /return|output|result/i.test(badPrompt);

  let refined = badPrompt;

  // เพิ่ม specificity ตามที่ขาด
  if (hasFunction && !hasParams) {
    refined += ' that takes an array of numbers as input';
  }
  if (!hasType) {
    refined += ' and returns a number';
  }
  if (!hasReturn) {
    refined += ' (the sum of all elements)';
  }

  return refined;
}
```

**Step 3: Run tests**

```bash
node test.js
```

**Step 4: ตรวจสอบ** — prompt ใหม่ต้องยาวกว่าเดิมและมี specificity

## ⚠️ Common Mistakes

**Mistake 1: คืน prompt เดิมโดยไม่แก้ไข**
> "prompt ดูโอเคแล้ว"
> → Test จะ fail เพราะ expects prompt ที่ยาวกว่าเดิม

**Mistake 2: เพิ่ม word ที่ไม่ได้เพิ่ม specificity**
> "write a function that does things with stuff"
> → ต้องเพิ่ม parameters, types, edge cases — ไม่ใช่แค่ word คลุมเครือ

**Mistake 3: ไม่ใส่ parentheses หรือ parameter names**
> "write a function for sorting"
> → ต้องมี parameter description เช่น "(array of numbers)"

**Mistake 4: ไม่ test prompt ใหม่**
> "เขียน prompt ใหม่แล้ว น่าจะดี"
> → ต้องรัน test เพื่อตรวจสอบว่า prompt ใหม่ดีกว่าจริง
