# Quest 1.1: First AI Completion

<Badge text="🟢 Easy" variant="success" /> <Badge text="15 minutes" variant="note" /> <Badge text="Block 1: AI Tools" variant="tip" />

## 🎯 Goal

ใช้ AI coding tool เขียน factorial function ตัวแรกของคุณ

---

## 📋 Instructions

<Steps>

1. **เปิด VS Code** และสร้างไฟล์ `factorial.js`

2. **เขียน comment** บอก AI ว่าต้องการอะไร:
   ```javascript
   // Calculate factorial of n using recursion
   ```

3. **รอ AI suggest** และกด Tab เพื่อรับ

4. **ทดสอบ function**:
   ```javascript
   console.log(factorial(5));   // 120
   console.log(factorial(10));  // 3628800
   ```

</Steps>
