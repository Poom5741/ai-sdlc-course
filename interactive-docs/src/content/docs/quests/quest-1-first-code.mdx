## 💡 Hints

- **Base case**: factorial(0) = 1, factorial(1) = 1
- **Recursive case**: factorial(n) = n × factorial(n-1)
- **Edge case**: factorial ของเลข **ลบ** ไม่มีนิยาม — ต้อง `throw` ไม่ใช่ return 1
- **Verify before trust**: ลอง test กับเลข 0, 1, 5, 10 และ -1
