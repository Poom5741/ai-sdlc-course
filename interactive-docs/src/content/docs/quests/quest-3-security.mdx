# Quest 3.1: Spot the Vulnerability

<Badge text="🟢 Easy" variant="success" /> <Badge text="15 minutes" variant="note" /> <Badge text="Block 3: Security" variant="tip" />

## 🎯 Goal

ตรวจหา security vulnerabilities ในโค้ดที่ AI generate แล้วเรียนรู้การ **assume AI code is insecure**

---

## 📋 Instructions (รันบนเครื่องของคุณ)

<Steps>

1. **ดึงไฟล์ quest ลงเครื่อง**:
   ```bash
   npx degit Poom5741/ai-sdlc-course/quests/block-3-security/quest-07-spot-vulnerability my-quest
   cd my-quest
   ```

2. **อ่าน `vulnerable.js`** — โค้ดที่ต้องตรวจสอบ (ใช้ AI ช่วย audit ได้)

3. **ระบุ vulnerabilities ทั้งหมด** แล้วเขียนลงใน `problem.js` เป็น array ของ `{ type, severity, description, fix }`

4. **ตรวจสอบ**:
   ```bash
   node test.js
   ```

</Steps>

---

## ✅ Verification

```bash
node test.js
```

`test.js` ตรวจว่าคุณระบุ vuln type ครบ (SQL Injection, Hardcoded Secrets, Weak Password Hashing, Path Traversal, XSS) พร้อม severity/description/fix

> คุณต้อง **ระบุ** ไม่ใช่แก้ — อย่าแก้ `vulnerable.js`

> ติดขัด? แอบดู `_solution/solution.js` ได้ แต่ลอง audit เองก่อน

---

## 🔍 Common Vulnerabilities

| Vulnerability | Severity | Fix |
|--------------|----------|-----|
| SQL Injection | critical | Parameterized queries |
| Hardcoded Secrets | critical | Environment variables |
| Weak Hashing | high | bcrypt/argon2 |
| Path Traversal | high | Sanitize paths |
| XSS | high | Escape HTML |
