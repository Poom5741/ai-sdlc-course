# Quest 3.2: Fix and Harden

<Badge text="🟡 Medium" variant="note" /> <Badge text="20 minutes" variant="note" /> <Badge text="Block 3: Security" variant="tip" />

## 🎯 Goal

ให้ AI **fix + harden** code ที่มีช่องโหว่ — เรียนรู้การแก้ **class ไม่ใช่ instance** (แก้ pattern ของช่องโหว่ ไม่ใช่แค่ตัวอย่างเดียว)

---

## 📋 Instructions (รันบนเครื่องของคุณ)

<Steps>

1. **ดึง quest ลงเครื่อง:**
   ```bash
   npx degit Poom5741/ai-sdlc-course/quests/block-3-security/quest-08-fix-harden my-quest
   cd my-quest
   ```

2. **นึกถึง SQL injection จาก Quest 3.1**

3. **เขียน prompt ที่แก้ทั้ง class**: parameterized query + input validation ที่ boundary

4. **Generate `safeQuery(id)`** (return `{ query, params }` โดยมี `?` placeholder)
   และ **`validateUserId(s)`** (reject ที่ไม่ใช่ตัวเลข / ว่าง / null / ติดลบ / injection payload)

5. **ตรวจสอบ:**
   ```bash
   node test.js
   ```

</Steps>

---

## ✅ Verification

```bash
node test.js
```

`node test.js` เช็ค: `safeQuery("1 OR 1=1")` return shape ที่เป็น parameterized (query มี `?`, payload อยู่แค่ใน `params`, ไม่เคยอยู่ใน query text); `validateUserId` ยอมรับตัวเลขที่ valid และ reject empty/null/non-numeric/negative/injection

---

## 💡 Hints

- อย่าแค่ escape string ปัญหานั้น — แก้ **pattern**: placeholder + params
- Validation เกิดขึ้นที่ **boundary** (ก่อน query) ไม่ใช่ข้างใน
