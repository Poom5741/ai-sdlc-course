## 📖 Concept: Namespaced KV Keys

Cloudflare KV เป็น distributed key-value store ที่เร็วมาก — แต่ถ้าคุณใช้ key ที่ไม่มี structure เช่น `"data123"` หรือ `"user"` คุณจะปวดหัวเวลาต้อง manage ข้อมูลจำนวนมาก

**Namespace pattern** คือวิธีจัดระเบียบ keys ให้มี structure ชัดเจน เช่น `user:profile:123` หรือ `product:items:456` pattern นี้ทำให้:

- ค้นหา keys ได้ง่าย
- จัดกลุ่มข้อมูลตาม entity type
- หลีกเลี่ยง key collision

Think ของมันเหมือน "ระบบไฟล์" — namespace เหมือนโฟลเดอร์, entity เหมือน subfolder, และ id เหมือนชื่อไฟล์

---

## ⚙️ How It Works

### Key Generation Flow

```
1. รับ namespace, entity, id, action
         ↓
2. Validate inputs (ทุกตัวต้องไม่ empty)
         ↓
3. ตรวจสอบ action ใน ACTION_TTL map
         ↓
4. สร้าง key: "namespace:entity:id"
         ↓
5. Return { key, ttl }
```

### Key Format

```
namespace:entity:id
     ↓       ↓     ↓
   "user"  "profile" "123"
   → user:profile:123
```

### TTL (Time-To-Live) by Action

| Action | TTL | ความหมาย |
| --- | --- | --- |
| `read` | 0 | ไม่มี expiration (ใช้ค่า default ของ KV namespace) |
| `write` | 3600 | หมดอายุใน 1 ชั่วโมง |
| `delete` | 0 | ไม่มี expiration |

## 💡 Example: Building KV Keys

**ขั้นตอนที่ 1: กำหนด ACTION_TTL map**

```javascript
const ACTION_TTL = {
  read: 0,
  write: 3600,
  delete: 0,
};
```

**ขั้นตอนที่ 2: Validate inputs**

```javascript
if (!namespace || namespace.trim() === '') {
  return { key: '', error: 'namespace is required' };
}
if (!entity || entity.trim() === '') {
  return { key: '', error: 'entity is required' };
}
if (!id || id.trim() === '') {
  return { key: '', error: 'id is required' };
}
if (!ACTION_TTL.hasOwnProperty(action)) {
  return { key: '', error: `invalid action: ${action}` };
}
```

**ขั้นตอนที่ 3: สร้าง key**

```javascript
const key = `${namespace}:${entity}:${id}`;
const ttl = ACTION_TTL[action];

return { key, ttl };
```

**ตัวอย่างผลลัพธ์:**

```javascript
buildKVKey('user', 'profile', '123', 'write');
// → { key: 'user:profile:123', ttl: 3600 }

buildKVKey('product', 'items', '456', 'read');
// → { key: 'product:items:456', ttl: 0 }

buildKVKey('', 'profile', '123', 'read');
// → { key: '', error: 'namespace is required' }
```

## ⚠️ Common Mistakes

**Mistake 1: ไม่ validate inputs ก่อนสร้าง key**
> "inputs จะต้องมีค่าอยู่แล้ว"
> → Caller อาจส่ง empty string — validate เสมอก่อนสร้าง key

**Mistake 2: ไม่ check action ใน ACTION_TTL map**
> ใช้ action ที่ไม่มีใน map เช่น `"update"`
> → ต้อง check `hasOwnProperty` ก่อนใช้ action

**Mistake 3: ลืม strip whitespace จาก inputs**
> `"  user  "` กลายเป็น key ที่มี space
> → ใช้ `.trim()` กับ inputs เสมอ

**Mistake 4: ใช้ separator ที่ไม่ consistent**
> ใช้ `/` ในที่หนึ่งและ `:` ในอีกที่หนึ่ง
> → เลือก separator ตัวเดียว (เช่น `:`) แล้วใช้ตลอด

## คำใบ้

- Key format คือ `namespace:entity:id` คั่นด้วย colon
- ACTION_TTL map: read=0, write=3600, delete=0
- ใช้ `.trim()` กับ inputs เสมอก่อน validate
- ตรวจสอบ `hasOwnProperty` สำหรับ action
