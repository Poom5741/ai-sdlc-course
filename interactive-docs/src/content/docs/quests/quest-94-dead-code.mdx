## 📖 Concept: Dead Code & Safe Elimination

Dead code คือ code ที่เขียนไว้แต่ไม่เคยถูกเรียกใช้ — มันเหมือนนักสู้ที่อยู่ในค่ายแต่ไม่เคยลงสนาม ดูเหมือนไม่เป็นอะไร แต่จริงๆ แล้วมันเพิ่ม maintenance burden และซ่อน bug

ปัญหาคือ AI tools มักจะ suggest ให้ลบ **ทุก function ที่ดูไม่ถูกเรียก** — แต่มันลืม考慮ว่า exported function อาจถูกใช้โดย module อื่น ที่มองไม่เห็นในโค้ดที่กำลัง refactor

Think of dead code elimination like cleaning out your dojo equipment room. You want to throw away what's truly unused, but you must NOT throw away tools that other dojos are borrowing through shared exports.

## ⚙️ How It Works

### The Dead Code Analysis Workflow

1. **Parse the code** — extract function declarations, variable declarations, and imports
2. **Build a dependency graph** — map which identifiers reference which declarations
3. **Mark exports as alive** — anything exported via `module.exports` or `export` is NOT dead
4. **Identify dead code** — declarations with no references and no exports

### What Counts as Dead Code?

```javascript
// ✅ DEAD: unused function (never called, not exported)
function unusedHelper() { return 1; }

// ❌ NOT DEAD: used by another function
function used() { return usedHelper2(); }
function usedHelper2() { return 2; }

// ❌ NOT DEAD: exported (may be used by other modules)
function helper() { return 1; }
module.exports = { helper };
```

### Detection Strategy

```javascript
function findDeadCode(code) {
  // 1. Find all function declarations: function xxx()
  // 2. Find all variable declarations: const/let/var xxx =
  // 3. Find all imports: require("...") or import ...
  // 4. Find all exports: module.exports = { ... }
  // 5. Check: is each declaration referenced elsewhere?
  // 6. Check: is each declaration exported?
  // 7. If not referenced AND not exported → it's dead code
}
```

## 💡 Example: Walkthrough

```javascript
// Input code
const code = `function unused() { return 1; }
function used() { return used2(); }
function used2() { return 2; }`;

// Analysis:
// - "unused" → never called, not exported → DEAD ❌
// - "used" → called by nobody? Wait, it IS referenced... no, nobody calls used()
// - "used2" → called by used() → NOT dead ✅

// Output:
[{ name: 'unused', type: 'function' }]
```

Key edge case: `module.exports = { helper }` means `helper` is exported — even if no other code in this file calls it, it's NOT dead code.

## ⚠️ Common Mistakes

**Mistake 1: Flagging exported functions as dead code**
> "helper ไม่ถูกเรียกในไฟล์นี้ → ลบเลย"
> → Exported functions ถูกใช้โดย module อื่น — **ห้ามลบ**

**Mistake 2: Not handling `require()` imports**
> "fs ไม่ถูกใช้ → ยังไม่ใช่ dead code เพราะ require ไม่ได้ declare"
> → `const fs = require("fs")` ถ้าไม่ใช้ fs ที่ไหนเลย → มันเป็น dead import ✅

**Mistake 3: Only checking function names**
> "ลบทุก function ที่ไม่เห็นว่าถูกเรียก"
> → ต้องตรวจสอบ **variable declarations** และ **imports** ด้วย

**Mistake 4: Empty input crashes**
> "ไม่ได้เช็คว่า code ว่าง"
> → Always handle empty input — return empty array
