# Quest 4.3: Multi-Agent Pipeline

<Badge text="🔴 Hard" variant="danger" /> <Badge text="25 minutes" variant="note" /> <Badge text="Block 4: Agentic Workflows" variant="tip" />

## 🎯 Goal

Orchestrate agent หลายบทบาท (code writer, test writer, test runner) — เรียนรู้ **anti-bamboozle architecture**: agent ที่เขียน test ต้องเป็น **function object ที่ต่างกัน** จาก agent ที่รัน test; ไม่อย่างนั้น test จะไม่ independent และ implementation ขี้เกียจจะผ่าน test ของตัวเอง

---

## 📋 Instructions (รันบนเครื่องของคุณ)

<Steps>

   npx degit Poom5741/ai-sdlc-course/quests/block-4-agentic-workflows/quest-12-multi-agent my-quest

2. **อ่าน contract ใน `problem.js`**: `buildPipeline({ codeWriter, testWriter, testRunner })` return pipeline ที่มี `writeCode`, `writeTests`, `runTests` stages พร้อม role functions ทั้งสามที่ถูกอ้างอิง

3. **Prompt ให้ `buildPipeline`** — สั่งอย่างชัดเจน: `testWriter` และ `testRunner` ต้องเป็น object ที่ต่างกัน — ห้าม collapse เป็น reference เดียว

4. **ตรวจสอบ:**
   ```bash
   node test.js
   ```

## ✅ Verification

```bash
node test.js
```

`node test.js` ยืนยัน: `pipeline.testWriter !== pipeline.testRunner` (anti-bamboozle), stages ทั้งสามเป็น function ที่ wire กับ role functions ที่ caller ส่งเข้า (reference เดียวกัน — ไม่มี agent ปลอม), และ end-to-end (`writeCode → writeTests → runTests`) ให้ object kinds ที่คาด

---

## 💡 Hints

- AI ธรรมดามัก assign `testRunner = testWriter` "เพื่อความง่าย" — นั่นคือ failure mode ที่ quest นี้สอนให้คุณจับ
- Pipeline ต้อง **expose** role functions ที่มัน wire เข้าไว้ เพื่อให้ caller/test ตรวจได้ว่าไม่มี agent โดนแทนที่ด้วย fake ที่ผ่านเสมอ
- reference-equality checks (`pipeline.codeWriter === codeWriter`) จับ pipeline ที่แอบใส่ "always-pass" agents
