## 📖 Concept: Agent Loop Pattern

Agent Loop คือหนึ่งใน pattern ที่สำคัญที่สุดของ Agentic Workflows — มันคือรอบการทำงานที่ agent **สร้างงาน → ตรวจสอบ → แก้ไข → วนซ้ำ** จนกว่าจะได้ผลลัพธ์ที่ยอมรับได้

ลองนึกภาพว่าคุณกำลังเขียนบทความ — คุณเขียนร่างแรก แล้วให้ editor ตรวจสอบ ถ้า editor บอกว่ายังไม่ดีพอ คุณก็แก้ไขแล้วส่งตรวจสอบอีกครั้ง **Agent Loop ทำแบบเดียวกันแต่เป็น code**

```javascript
// วงจร Agent Loop
const result = agentLoop(generator, reviewer, maxIterations);
// generator:  สร้าง draft จาก feedback ก่อนหน้า
// reviewer:   ตรวจสอบ draft แล้ว approve/reject พร้อม feedback
// maxIterations: จำนวนรอบสูงสุด (ป้องกัน infinite loop!)
```

สิ่งที่สำคัญคือ **ทุก loop ต้องมี exit condition** — ไม่เช่นนั้นถ้า reviewer ไม่เคย approve loop จะทำงานตลอดกาล

---

## ⚙️ How It Works

### วงจร Agent Loop

```
1. generator สร้าง draft จาก 'initial' (รอบแรก) หรือ feedback ก่อนหน้า
         ↓
2. reviewer ตรวจสอบ draft
         ↓
3. ถ้า approved === true → หยุด loop, return result
         ↓
4. ถ้า approved === false → บันทึก history, วนซ้ำกับ feedback ใหม่
         ↓
5. ถ้า iterations >= maxIterations → หยุด loop, return draft สุดท้าย
```

### ทำไมต้องมี Max Iterations?

ในโลกจริง reviewer อาจไม่เคยพอใจ หรือ generator อาจไม่สามารถสร้างงานที่ดีพอได้ ถ้าไม่มี max iterations guard:

```javascript
// ❌ อันตราย! Loop ไม่มีวันหยุด
while (!review.approved) {
  result = generator(review.feedback);
  review = reviewer(result);
}
```

```javascript
// ✅ ปลอดภัย — มี guard
for (let i = 0; i < maxIterations; i++) {
  result = generator(feedback);
  review = reviewer(result);
  if (review.approved) break;
}
```

## 💡 Example: Agent Loop ใน action

```javascript
// Generator: สร้าง draft จาก feedback
function generator(feedback) {
  if (feedback === 'initial') return 'draft v1';
  if (feedback.includes('more detail')) return 'draft v2 — with more detail';
  return 'final draft';
}

// Reviewer: ตรวจสอบ draft
function reviewer(draft) {
  if (draft.includes('final')) return { approved: true, feedback: '' };
  return { approved: false, feedback: 'need more detail' };
}

// Run the loop
const result = agentLoop(generator, reviewer, 5);
console.log(result);
// {
//   result: 'final draft',
//   iterations: 3,
//   history: [
//     { iteration: 1, draft: 'draft v1', approved: false, feedback: 'need more detail' },
//     { iteration: 2, draft: 'draft v2 — with more detail', approved: false, feedback: 'need more detail' },
//     { iteration: 3, draft: 'final draft', approved: true, feedback: '' }
//   ]
// }
```

**สังเกต:** ทุก iteration ถูกบันทึกใน history — ทำให้เราเห็นว่า feedback แต่ละรอบเปลี่ยนแปลง draft อย่างไร

## ⚠️ Common Mistakes

**Mistake 1: ไม่มี max iterations guard**
> "Reviewer ต้อง approve สักวัน"
> → ไม่เสมอไป! ต้องมี max iterations เพื่อป้องกัน infinite loop

**Mistake 2: ไม่ส่ง feedback ให้ generator**
> generator ได้รับ 'initial' ทุกรอบ
> → ต้องส่ง feedback จาก review ก่อนหน้าให้ generator เพื่อให้รู้ว่าต้องแก้ไขอะไร

**Mistake 3: ไม่บันทึก iteration history**
> "แค่ return result ก็พอ"
> → History ช่วย debug และเข้าใจว่า loop ทำงานอย่างไร — มันคือ audit trail

**Mistake 4: คิดว่า iteration = ความล้มเหลว**
> "Loop หลายรอบ = ไม่ดี"
> → ไม่จริง! Agent loop ที่ดี **ควร** วนหลายรอบ — นั่นคือจุดประสงค์ของมัน
