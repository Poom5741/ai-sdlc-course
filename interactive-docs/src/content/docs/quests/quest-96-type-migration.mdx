# Type Migration Assistant

<Badge text="hard" variant="danger" /> <Badge text="30-45 minutes" variant="note" />

## เป้าหมาย

Migrate JavaScript to TypeScript with proper types

---

## วิธีทำ

<Steps>

1. Download ไฟล์เริ่มต้นของ quest:
   ```bash
   npx bluebeltdojo download quest-96-type-migration
   cd quest-96-type-migration
   ```

2. เปิด `problem.js` ใน editor ของคุณพร้อมความช่วยเหลือของ AI

3. Implement solution ตาม instructions ใน `problem.js`

4. ตรวจสอบ solution ของคุณ:
   ```bash
   node test.js
   ```

</Steps>

---

## การตรวจสอบ

```bash
node test.js
```

When all tests pass, you will see the completion message.

---

## ส่งคำตอบ

When tests pass, submit your solution:

```bash
npx bluebeltdojo submit
```

> ต้องตั้งค่า access code ก่อน: `npx bluebeltdojo setup <code>`

## คำใบ้

- อ่าน instructions ใน `problem.js` อย่างละเอียด
- ตรวจสอบ edge cases ที่กล่าวถึง
- ถ้าติดขัด ดู `_solution/solution.js`
