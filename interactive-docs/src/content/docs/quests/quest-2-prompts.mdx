# Quest 2.1: Fix the Vague Prompt

<Badge text="🟢 Easy" variant="success" /> <Badge text="15 minutes" variant="note" /> <Badge text="Block 2: Prompt Engineering" variant="tip" />

## 🎯 Goal

เปลี่ยน vague prompt ให้เป็น specific prompt ที่ระบุ constraints ครบ แล้วเรียนรู้การ **specify before generate**

---

## 📋 Instructions (รันบนเครื่องของคุณ)

<Steps>

1. **ดึงไฟล์ quest ลงเครื่อง**:
   ```bash
   npx degit Poom5741/ai-sdlc-course/quests/block-2-prompt-engineering/quest-04-fix-prompt my-quest
   cd my-quest
   ```

2. **วิเคราะห์ bad prompt** ใน `problem.js`:
   ```
   Make a function that handles users
   ```

3. **เขียน improved prompt** ระบุ constraints ครบ (input shape, email format, empty/null handling, success/error return shape):
   ```
   Create a function createUser(userData) that:
   - Takes { name: string, email: string }; handles {} and null
   - Validates email against user@domain.tld
   - Returns { success: false, error } on failure (never throws)
   - Returns { success: true, id, name, email } on success
   ```

4. **ใช้ AI generate** ตาม prompt แล้ว **ตรวจสอบ**:
   ```bash
   node test.js
   ```

</Steps>

กรอบข้อกำหนดที่ต้องผ่านทุกข้อ:

- email ผิดรูปแบบ → `{success:false,error}`

> ติดขัด? แอบดู `_solution/solution.js` ได้ แต่ลองเขียน prompt เองก่อน

## 💡 Tips

A good prompt specifies, before generating:
1. **Function name and purpose**
2. **Input shape** with types
3. **Output shape** (success + error)
4. **Validation rules**
5. **Error handling** (returns, never throws)
