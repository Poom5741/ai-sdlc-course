## 📖 Concept: Tool Registry Pattern

Tool Registry คือ central hub ที่เก็บ tools ทั้งหมดของ agent — ทำหน้าที่เหมือน "สมุดโทรศัพท์" สำหรับ capabilities ต่างๆ ของระบบ

ใน Agentic Workflows, agent ต้อง **ค้นหา → เลือก → ใช้** tools ต่างๆ แบบ runtime แทนที่จะ hardcode ไว้ Tool Registry ทำให้ agent สามารถ discover และ dispatch tools ได้ตามต้องการ

```javascript
// Tool แต่ละตัวมี schema บอกว่ารับอะไร
const calculator = {
  name: 'calculator',
  description: 'Perform arithmetic calculations',
  parameters: {
    operation: { type: 'string', required: true },
    a: { type: 'number', required: true },
    b: { type: 'number', required: true },
  },
  execute: (args) => { /* ... */ }
};

const registry = createToolRegistry();
registry.register(calculator);
registry.execute('calculator', { operation: 'add', a: 2, b: 3 }); // 5
```

## ⚙️ How It Works

### วงจร Tool Registry

```
1. register(tool) — เพิ่ม tool ลง registry พร้อม parameter schema
         ↓
2. findTools(query) — ค้นหา tools ที่ตรงกับ keyword
         ↓
3. listTools() — แสดง tools ทั้งหมดที่ registered
         ↓
4. execute(toolName, args) — เรียกใช้ tool พร้อม validate args ก่อน
```

### ทำไมต้อง Validate Args?

ถ้าไม่ validate args ก่อน execute agent อาจส่ง arguments ผิดประเภท ทำให้เกิด runtime errors ที่ยากจะ debug:

```javascript
// ❌ ไม่ validate — อาจ crash
function execute(toolName, args) {
  return tools[toolName].execute(args); // args อาจขาด field จำเป็น
}

// ✅ Validate ก่อน execute
function execute(toolName, args) {
  const tool = tools[toolName];
  for (const [key, schema] of Object.entries(tool.parameters)) {
    if (schema.required && !(key in args)) {
      throw new Error(`Missing required parameter: ${key}`);
    }
  }
  return tool.execute(args);
}
```

## 💡 Example: Tool Registry ใน action

```javascript
const registry = createToolRegistry();

// Register tools
registry.register({
  name: 'search',
  description: 'Search the web',
  parameters: {
    query: { type: 'string', required: true },
    limit: { type: 'number', required: false },
  },
  execute: (args) => `Results for: ${args.query}`,
});

// Find tools by keyword
const found = registry.findTools('search');
// [{ name: 'search', description: 'Search the web', ... }]

// Execute with validation
registry.execute('search', { query: 'AI agents' }); // ✅ Works
registry.execute('search', {}); // ❌ Error: Missing required parameter: query
```

## ⚠️ Common Mistakes

**Mistake 1: ไม่ validate required parameters**
> "Just pass args through"
> → Registry ต้องตรวจสอบ required parameters ก่อน execute — ไม่เช่นนั้น runtime error

**Mistake 2: Hardcode tools แทนที่จะ register**
> "I'll just import the tools directly"
> → Agent ต้อง discover tools ตอน runtime — hardcoding ทำให้ไม่สามารถเพิ่ม/ลบ tools ได้

**Mistake 3: ไม่มี findTools functionality**
> "listTools ก็พอแล้ว"
> → Agent อาจมี tools หลายสิบตัว — findTools ช่วยค้นหาจาก keyword ได้เร็วกว่า

**Mistake 4: Return value ไม่ consistent**
> "execute คืนค่าต่างกันแล้วแต่ tool"
> → ทุก tool ควร return format ที่ consistent เพื่อให้ agent ใช้งานง่าย
