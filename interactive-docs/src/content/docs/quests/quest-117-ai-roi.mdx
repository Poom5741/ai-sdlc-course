## 📖 Concept: ROI — Return on Investment

**ROI (Return on Investment)** คือสูตรที่บอกว่า "invest ไป 1 บาท ได้กลับมาเท่าไหร่"

```
ROI = (Savings - Cost) / Cost × 100%

ถ้า ROI = 150%  →  ทุก ฿1 ลงทุน ได้กลับ ฿2.50
ถ้า ROI = -50%  →  ทุก ฿1 ลงทุน ขาดทุน ฿0.50
```

**สำหรับ AI tools ROI:**

```
┌──────────────────────────────────────────┐
│           AI ROI Calculation              │
│                                          │
│  COST = teamSize × monthlyCost × months  │
│                                          │
│  SAVINGS = teamSize × hoursSaved          │
│            × hourlyRate × weeks           │
│                                          │
│  ROI = (Savings - Cost) / Cost × 100%   │
│                                          │
│  Break-even = Cost / weeklySavings       │
└──────────────────────────────────────────┘
```

### Break-Even Analysis

**Break-even point** คือเวลาที่ savings เท่ากับ cost — หลังจากจุดนี้ทุกบาทคือ profit

ถ้า ROI เป็น negative → break-even = **Infinity** (ไม่มีวันคุ้ม!)

## ⚙️ How It Works

### Input Parameters

```javascript
{
  teamSize: 10,                    // จำนวน developers
  monthlyCostPerDev: 20,           // ค่าใช้จ่าย AI tool ต่อคนต่อเดือน ($)
  hoursSavedPerDevPerWeek: 5,      // เวลาที่บันทึกได้ต่อคนต่อสัปดาห์
  hourlyRate: 75,                  // ค่าแรงต่อชั่วโมง ($)
  weeksInQuarter: 13               // จำนวนสัปดาห์ใน 1 quarter
}
```

### Formulas

```javascript
// Total cost (3 months / 1 quarter)
totalCost = teamSize × monthlyCostPerDev × 3

// Total savings (per quarter)
totalSavings = teamSize × hoursSavedPerDevPerWeek × hourlyRate × weeksInQuarter

// Net benefit
netBenefit = totalSavings - totalCost

// ROI percentage
roi = (totalSavings - totalCost) / totalCost × 100

// Break-even weeks
weeklySavingsPerTeam = teamSize × hoursSavedPerDevPerWeek × hourlyRate
breakEvenWeeks = totalCost / weeklySavingsPerTeam
```

### Edge Cases

| Scenario | ROI | Break-even |
| --- | --- | --- |
| Good ROI (savings > cost) | Positive % | Finite weeks |
| Bad ROI (cost > savings) | Negative % | `Infinity` |
| Zero cost | N/A | `0` or `Infinity` |
| Zero savings | `-100%` | `Infinity` |

## 💡 Example: Calculating AI Tool ROI

**Scenario: Good investment**

```javascript
const result = calculateROI({
  teamSize: 10,
  monthlyCostPerDev: 20,        // $20/dev/month
  hoursSavedPerDevPerWeek: 5,   // 5 hours saved/dev/week
  hourlyRate: 75,               // $75/hour
  weeksInQuarter: 13
});

// totalCost = 10 × 20 × 3 = $600
// totalSavings = 10 × 5 × 75 × 13 = $48,750
// roi = (48750 - 600) / 600 × 100 = 8,025%
// breakEvenWeeks = 600 / (10 × 5 × 75) = 0.16 weeks
```

**Scenario: Bad investment**

```javascript
const badResult = calculateROI({
  teamSize: 10,
  monthlyCostPerDev: 200,       // $200/dev/month — expensive!
  hoursSavedPerDevPerWeek: 1,   // only 1 hour saved
  hourlyRate: 25,               // low hourly rate
  weeksInQuarter: 13
});

// totalCost = 10 × 200 × 3 = $6,000
// totalSavings = 10 × 1 × 25 × 13 = $3,250
// roi = (3250 - 6000) / 6000 × 100 = -45.83%
// breakEvenWeeks = Infinity  ← ไม่มีวันคุ้ม!
```

## ⚠️ Common Mistakes

**Mistake 1: Not handling negative ROI**
> "ROI is always positive because AI is good"
> → ถ้า cost > savings ROI จะ negative — code ต้อง handle case นี้

**Mistake 2: Returning a number instead of Infinity for impossible break-even**
> `breakEvenWeeks = -1` (or 0) for negative ROI
> → ใช้ `Infinity` — สื่อความหมายว่า "ไม่มีวัน break-even"

**Mistake 3: Ignoring edge cases**
> "Normal inputs always work"
> → ต้อง handle: zero cost, zero savings, negative values

**Mistake 4: Not rounding results**
> `roi: 8025.123456789`
> → Round to 2 decimal places เพื่อ readability
