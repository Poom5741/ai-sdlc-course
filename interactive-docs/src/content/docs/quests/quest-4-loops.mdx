## 🔄 PIV Loop Pattern

```
┌─────────────┐
│    PLAN     │
└──────┬──────┘
       ▼
┌─────────────┐
│  IMPLEMENT  │
└──────┬──────┘
       ▼
┌─────────────┐
│  VALIDATE   │
└──────┬──────┘
       ▼
   Pass? ──Yes──► Done
       │
       No ──► Back to PLAN
```
