## 📋 Instructions

<Steps>

1. **เข้าใจ PIV framework**

   - Implement: สร้าง code

2. **Implement loop controller**

3. **Test กับ simple task**

4. **Verify convergence**

## 🔄 PIV Loop Pattern

```
┌─────────────┐
│    PLAN     │
└──────┬──────┘
       ▼
┌─────────────┐
│  IMPLEMENT  │
└──────┬──────┘
       ▼
┌─────────────┐
│  VALIDATE   │
└──────┬──────┘
       ▼
   Pass? ──Yes──► Done
       │
       No ──► Back to PLAN
```
