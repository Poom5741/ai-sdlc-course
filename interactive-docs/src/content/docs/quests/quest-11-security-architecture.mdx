# Quest 3.3: Security Architecture

<Badge text="🔴 Hard" variant="danger" /> <Badge text="25 minutes" variant="note" /> <Badge text="Block 3: Security" variant="tip" />

## 🎯 Goal

ใช้ AI ออกแบบ security controls — เรียนรู้ที่จะ **threat-model ก่อน build**: หา threats ก่อน แล้ว control ต่อ threat แล้ว failure mode ของแต่ละ control

---

## 📋 Instructions

ดึง quest ลงเครื่องแล้วทำตามในเครื่องของคุณ:

```bash
npx degit Poom5741/ai-sdlc-course/quests/block-3-security/quest-09-security-architecture my-quest
cd my-quest
```

1. **เลือก system**: API auth flow (API key + rate limiting) ตาม spec
2. **สร้าง `design.md`** ในโฟลเดอร์นี้ โดยมี sections:
   - **System**: API auth flow ที่คุณกำลังรักษาความปลอดภัย
   - **Threats**: อย่างน้อย 3 threats
   - **Controls**: control ต่อ threat (รวม API key + rate limiting)
   - **Failure Modes**: เกิดอะไรขึ้นเมื่อแต่ละ control ล้มเหลว

---

## 💡 Hints

- **เริ่มจาก threats** — control ที่ไม่มี threat คือเครื่องประดับ
- ทุก control ต้องมี **failure mode** และ **fallback**
- ตัวอย่าง: credential theft → API key + rotation; abuse → rate limiting; brute force → uniform 401 + escalation
