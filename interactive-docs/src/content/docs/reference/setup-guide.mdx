# Pre-Workshop Setup Guide

<Badge text="Complete before workshop" variant="caution" />

## 🎯 Goal

เตรียม environment ให้พร้อมก่อนเข้า workshop เพื่อให้เริ่มเรียนได้ทันที

---

## Required Setup

### 1. GitHub Account

<Steps>

1. **ไปที่** [github.com](https://github.com)
2. **สมัครสมาชิก** ถ้ายังไม่มี account
3. **Verify email** ให้เรียบร้อย

</Steps>

### 2. VS Code

<Steps>

1. **Download** [VS Code](https://code.visualstudio.com/)
2. **Install** ตามขั้นตอน
3. **เปิด VS Code** ตรวจสอบว่าทำงานได้

</Steps>

### 3. Node.js

<Steps>

1. **Download** [Node.js](https://nodejs.org/) (version 18+)
2. **Install** ตามขั้นตอน
3. **ตรวจสอบ版本**:
   ```bash
   node --version
   npm --version
   ```

</Steps>

### 4. Git

<Steps>

1. **Download** [Git](https://git-scm.com/)
2. **Install** ตามขั้นตอน
3. **ตรวจสอบ**:
   ```bash
   git --version
   ```

</Steps>

---

## AI Tools Setup

### GitHub Copilot

<Steps>

1. **เปิด VS Code**
2. **ไปที่ Extensions** (Ctrl+Shift+X)
3. **ค้นหา** "GitHub Copilot"
4. **Install** extension
5. **Sign in** ด้วย GitHub account
6. **ตรวจสอบ**: จะเห็น icon ของ Copilot ใน status bar

</Steps>

### Claude Code (Optional)

<Steps>

1. **Install** ผ่าน terminal:
   ```bash
   npm install -g @anthropic-ai/claude-code
   ```
2. **ตรวจสอบ**:
   ```bash
   claude --version
   ```

</Steps>

---

## Verify Setup

ทดสอบว่าทุกอย่างทำงาน:

```bash
# ตรวจสอบ Node.js
node --version
# ควรแสดง v18.x.x หรือสูงกว่า

# ตรวจสอบ npm
npm --version
# ควรแสดง 9.x.x หรือสูงกว่า

# ตรวจสอบ Git
git --version
# ควรแสดง git version 2.x.x
```

---

## Troubleshooting

### Problem: `node: command not found`

**Solution**: ติดตั้ง Node.js ใหม่ หรือ restart terminal

### Problem: `git: command not found`

**Solution**: ติดตั้ง Git ใหม่ หรือ restart terminal

### Problem: Copilot ไม่ทำงาน

**Solution**:
1. ตรวจสอบว่า sign in แล้ว
2. Restart VS Code
3. ตรวจสอบ internet connection
