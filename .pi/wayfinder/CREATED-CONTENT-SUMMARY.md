## The AI Development Pipeline Structure

```
┌─────────────────────────────────────────────────────────────────┐
│  LAYER 1: PLANNING (Matt's Skills)                             │
│  ─────────────────────────────────────────────────────────────  │
│  Input: Loose idea, requirements, problems                     │
│  Tools: grilling → domain-modeling → wayfinder → research      │
│  Output: GitHub issues with clear decision tickets             │
└─────────────────────────────────────────────────────────────────┘
                              ↓
┌─────────────────────────────────────────────────────────────────┐
│  LAYER 2: TRACKING (GitHub Issues)                             │
│  ─────────────────────────────────────────────────────────────  │
│  Input: Decision tickets from planning                         │
│  Format: Issues with wayfinder labels, blocking relationships  │
│  Output: Ordered queue of implementable work                   │
└─────────────────────────────────────────────────────────────────┘
                              ↓
┌─────────────────────────────────────────────────────────────────┐
│  LAYER 3: EXECUTION (Goal System)                              │
│  ─────────────────────────────────────────────────────────────  │
│  Input: GitHub issues from queue                               │
│  Tools: /goal, /list, /loop commands                           │
│  Execution skills: Impeccable, Ponytail, Pi Agent skills       │
│  Output: Implemented, audited, verified work                   │
└─────────────────────────────────────────────────────────────────┘
```
