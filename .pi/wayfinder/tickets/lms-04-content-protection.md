# Ticket: Content Protection Scope Decision

## Question

Which content should be behind the paywall?

**Options:**

1. **All Content Protected**
   - Workshop blocks
   - Reference docs
   - Quests/challenges
   
2. **Workshop + Quests Only**
   - Workshop blocks (protected)
   - Reference docs (open)
   - Quests (protected)

3. **Workshop Only**
   - Workshop blocks (protected)
   - Reference docs (open)
   - Quests (open)

4. **Tiered Access**
   - Free: Overview, setup guide
   - Basic: Workshop blocks
   - Premium: Workshop + Reference + Quests

**Considerations:**
- Reference docs may drive SEO/traffic
- Quests are the hands-on value
- Workshop is the core product
- Some content should be free for marketing

**Recommendation:** Option 2 (Workshop + Quests Only)

- **Open**: Overview, Setup Guide, Reference Docs (SEO + marketing)
- **Protected**: Workshop Blocks, Quests (core value)

This lets people see what's available, but requires payment for the actual learning experience.
