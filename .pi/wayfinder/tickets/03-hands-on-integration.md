# Ticket: Hands-on Integration Decision

## Question

Should skills content include hands-on CTF challenges or remain documentation-only?

**Options:**
1. **Documentation Only** - Explain skills conceptually, let learners practice on their own projects
2. **Guided Exercises** - Step-by-step walkthroughs using the course's existing project
3. **CTF Challenges** - Create new quest(s) specifically for practicing skills
4. **Interactive Demos** - Live code examples showing skills in action (not graded)

**Considerations:**
- Current CTF structure: 5 quests with progressive difficulty
- Skills are tools, not features to build
- Practicing skills requires real projects, not contrived examples
- Workshop time is limited
- Self-serve learners need practice opportunities

**Recommendation:** Option 2 (Guided Exercises) + Option 4 (Interactive Demos) - Create guided walkthroughs using the course project as context, with interactive code examples showing skill workflows. Avoid formal CTF challenges since skills are meta-tools, not buildable features.
