# Wayfinder Map: Skills Content for AI SDLC Course

## Destination

Document the **AI Development Pipeline** - how skills work together as a system:

```
Matt Skills (Planning) → GitHub Issues (Tracking) → Goal System (Execution)
```

- **Planning Layer**: Matt's skills (grilling, domain-modeling, wayfinder) → Output: GitHub issues
- **Tracking Layer**: GitHub Issues as decision tickets
- **Execution Layer**: Goal system automates implementation with auditing
- **Execution Skills**: Impeccable, Ponytail, Pi Agent skills used within goals

Content should teach this pipeline as the core workflow, not just list individual skills.
